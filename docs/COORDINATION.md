## Правила

- Каждая задача живёт в своей копии (`git worktree` в `.claude/worktrees/`) и своём терминале.
- Перед выдачей задачи на общий файл — `python3 ~/.config/i3/claude/overlap.py <папка части>`;
  красное («одни строки») — задачи разводим по зонам или ставим в очередь.
- Merge пул-реквестов, пуш главной ветки и деплой — только рукой владельца.
- Запретные зоны (без личного разрешения владельца): `app/api/payments/**`, `app/api/orders/**`,
  `app/api/admin/login/**`, `app/api/whatsapp/webhook/**`, `supabase/migrations/**`,
  `src/lib/supabase/admin.ts`, `proxy.ts`, `.env*`.
- Тесты в копии: `export PATH="/home/room/.nvm/versions/node/v24.21.0/bin:$PATH"; npm test`.
  На главной ветке 18.09.2026 — 268 pass / 0 fail.

  этой части невозможны. Рабочий блок лежит в `~/.ssh/windows/config`, но `IdentityFile` указывает на
  `~/.ssh/dcbakery_deploy`, а ключ — в `~/.ssh/windows/dcbakery_deploy`. Ключ живой (проверено).
- **PR #20** — бизнес-условие (минимум 15 000 ₸, порог бесплатной доставки): подтвердить или менять.

  оформлять или выбрасывать.

  `mcp__claude_ai_Supabase__execute_sql`: любой SQL в боевой базе (там же заказы клиентов) без
  вопроса. Две трети остальных правил — мёртвые следы Windows.
